# Badge artwork

Brand icon paths: [Simple Icons 10.0.0](https://github.com/simple-icons/simple-icons/tree/10.0.0/icons) (CC0; trademarks remain their owners’ property). Text-only badges are intentional when no logo is bundled.

The WakaTime badge uses the WakaTime icon from the same Simple Icons release and a classic flat badge layout. Its width is calculated from the current all-time total by `scripts/profile.py`; do not edit the generated SVG manually.
